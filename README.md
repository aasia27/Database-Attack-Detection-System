# Database Attack Detection and Prevention System Using Python and Oracle

## Project Overview

This project is a web-based security system that detects SQL Injection attacks in login requests and logs them in an Oracle Database.

The system analyzes user inputs in real time and prevents unauthorized database access by identifying malicious SQL patterns.

It also provides a security dashboard to monitor suspicious activities.

---

## Features

* Secure login system
* SQL Injection attack detection
* Attack logging in Oracle Database
* Security dashboard to monitor attacks
* Web interface built using Flask

---

## Technologies Used

* Python
* Flask Framework
* Oracle Database 21c XE

## Database Configuration

Ensure Oracle XE is installed and running.

Connection Details Used:

```
Host: 127.0.0.1
Port: 1522
Service Name: xepdb1
Username: system
Password: system
```

---

## Database Setup

Run these SQL commands in SQL*Plus:

```
ALTER SESSION SET CONTAINER = XEPDB1;

CREATE TABLE users (
    id NUMBER PRIMARY KEY,
    username VARCHAR2(50),
    password VARCHAR2(50)
);

INSERT INTO users VALUES (1,'admin','admin123');

CREATE TABLE attack_logs (
    id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    username VARCHAR2(50),
    input_text VARCHAR2(4000),
    attack_type VARCHAR2(100),
    log_time TIMESTAMP DEFAULT SYSTIMESTAMP
);
```

```

Password: admin123
```

```

Password: test
```

The system will:

1. Detect the attack
2. Block the login attempt
3. Log the attack in the database
4. Display the attack in the dashboard
